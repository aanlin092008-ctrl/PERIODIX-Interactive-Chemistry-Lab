# PERIODIX – Interactive Chemistry Lab

An interactive chemistry learning platform designed to make chemistry exploration engaging and accessible.

## Features
- Interactive periodic table with 118 elements
- Element search and information cards
- 3D atomic structure visualization
- Interactive periodic trends learning
- Trend Quest chemistry quiz
- Score tracking and challenges

## Technologies Used
- HTML
- CSS
- JavaScript
- Three.js
